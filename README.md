# s.patwary

Personal portfolio of Sakib Patwary, a Software Developer based in Dhaka, Bangladesh. A Spotify-inspired interface showcasing projects, experience, skills, and music.

**[View live website](https://sakibpatwary.github.io/)**

## Tech stack

React, Vite, Tailwind CSS, Framer Motion, and EmailJS.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The static website is generated in `dist/` and hosted on GitHub Pages.
